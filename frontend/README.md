# booking-frontend

Статична сторінка бронювання столика й перегляду власних бронювань за
телефоном. Працює з `booking-service`: у контейнері — через Nginx за адресою
`/api/`, відкрита як файл — з `http://localhost:3000` (інша адреса — параметр
`?api=`).

```bash
npm test   # тести валідації форми
```

`Dockerfile` — багатоетапний: на Node.js проганяються lint і тести, а в образ
`nginx:alpine` копіюються лише статичні файли та `nginx.conf`, який проксіює
`/api/` до сервісу `booking-service`.
